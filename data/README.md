# 训练数据（新闻管理平台场景）

当前训练脚本读取 CSV，要求至少包含两列：

- `text`：待审核的内容（标题/正文/摘要/评论等）
- `label`：二分类标签，`0=正常可发布`，`1=敏感/违规需拦截`

默认示例：`sample_sensitive.csv`

## 标签口径（建议在答辩中明确）

### `label=0`（正常）

用于“新闻发布平台”最常见的合规内容，包括：

- 政务公告、政策解读、民生服务、天气预警、交通信息、企业公告等
- 合规报道：涉及违法犯罪关键词但属于**权威通报/辟谣/科普/风险提示**（例如“警方通报”“辟谣”“防诈骗提示”）
- 对违规行为的**批判性报道**或**风险提醒**，不包含引流/交易/传播方式

### `label=1`（敏感/违规）

平台通常需要拦截或人工复核的内容，例如：

- 诈骗引流：刷单返现、贷款手续费、冒充客服/官方、红包链接、验证码钓鱼等
- 非法交易：违禁品、假证、外挂、账号/银行卡四件套、对公账户等
- 谣言与煽动：未经证实的爆炸/投毒等重大事件、煽动对抗执法、组织聚众等
- 色情招嫖、赌博推广、资金盘拉人头、虚假“高收益”理财
- 人身攻击/仇恨歧视、网暴号召
- 隐私泄露：身份证、住址、手机号等可识别信息或“曝光求网暴”

## 数据构建建议（越像真实业务越好）

- 数据来源：后台发布记录、审核拦截日志、投诉/举报样本、历史公告与报道文本
- 多样性：标题/正文/摘要/评论区分别采样；同义改写、不同表达、错别字/谐音、带空格/符号
- 难例（强烈建议）：加入“硬负样本”
  - 例如包含“爆炸/投毒/刷单/转账”等词，但语义是“辟谣/通报/防骗提示”的样本应标为 0
- 类别平衡：正负样本数量尽量接近；或至少保证每类都有足够样本（建议每类 500+ 起步）
- 质量控制：统一标注口径；对分歧样本做二次复审；定期抽检

## CSV 扩展

你可以额外增加列（例如 `id`/`source`/`channel`/`time`/`reason`），训练脚本只读取 `text,label`。
